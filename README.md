# EX No.4.2. CUT SECTION OF SOLIDS
## DATE:19-11-2026

## AIM: 
To create a 3D solid model of the given stemmed goblet/bowl (Exercise 4.2) and 
generate its 2D orthographic and isometric views using 3D CAD modeling software.
## REQUIREMENTS: 
* Operating System: Windows 10 or Windows 11 (64-bit). 
* Processor: Intel Core i5 / AMD Ryzen 5 or higher. 
* RAM: Minimum 8 GB (16 GB recommended). 
* Graphics: Dedicated GPU with 2 GB VRAM or integrated graphics supporting 
OpenGL/DirectX. 
* Storage: Minimum 10 GB free disk space. 
* Software: 3D CAD Modeling Software (such as SolidWorks, AutoCAD 3D, Creo 
Parametric, CATIA, or Autodesk Inventor). 
## PROCEDURE:
Step 1: Select the Sketch Plane 
*Select the Front Plane. 
*Click on Create Sketch. 
*Observe the coordinate system. 
*Select the required drawing area. 
*Prepare the workspace for drawing the wine glass profile

Step 2: Create the Bowl Profile 
*Select the Arc tool. 
*Draw the outer bowl profile. 
*Set the outer line to 1.501 mm. 
*Draw the inner bowl profile. 
*Set the inner radius to R2.113 mm. 
*Maintain the required curved shape. 
*Check the dimensions carefully.
<img width="665" height="410" alt="Screenshot 2026-11-20 235001" src="https://github.com/user-attachments/assets/698873c2-8002-4e62-aadd-1da11c5dc7cc" />
Step3:Create the Bowl Opening 
*Select the Line and Arc tools. 
*Draw the upper opening of the bowl. 
*Set the outer diameter to 452.2 mm. 
*Set the inner diameter to 427.6 mm. 
*Connect the inner and outer profiles. 
*Ensure that the bowl profile is 
*Draw two parallel vertical lines below the bowl. 
*Set the stem width to 24.6 mm. 
<img width="527" height="442" alt="Screenshot 2026-11-20 235653" src="https://github.com/user-attachments/assets/3f6f744b-1ba8-48ae-93b6-7c50dc7fbc91" />
Step4: Create the Stem Connection 
*Select the Arc or Line tool. 
*Draw the connection between the stem and bowl. 
*Maintain the centre alignment. 
*Use the given drawing as a reference. 
*Ensure that the connection is smooth. 
*Check the sketch before proceeding. 
*Select the required circular profile. 
*Use the Extrude command. 
*Set the base thickness to 14.8 mm.

Step 5: Complete the Wine Glass Profile 
*Check all the sketch dimensions. 
*Verify the bowl, stem and base connections. 
*Remove unwanted sketch lines. 
*Ensure that the profile is properly closed. 
*Check the overall shape of the wine glass. 
<img width="450" height="286" alt="WhatsApp Image 2026-11-20 at 00 25 17" src="https://github.com/user-attachments/assets/45f675ba-3321-4826-b06b-e9c48e12d5cf" />
Step 6: Apply the Revolve Command 
*Select the Revolve tool. 
*Choose the complete sectional profile. 
*Select the vertical centre line as the axis. 
*Enter the revolution angle as 360°. 
*Select the Join operation if required. 
*Click OK to create the 3D model.
